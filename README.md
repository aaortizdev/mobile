# 🌤️ App Meteorológica

Aplicación móvil de **información meteorológica** desarrollada para consultar las condiciones climáticas de diferentes ciudades del Ecuador de manera sencilla y rápida.

## 📱 Descripción

La aplicación permite al usuario seleccionar una ciudad y consultar información relacionada con el clima.

Actualmente, la aplicación cuenta con información meteorológica para las siguientes ciudades:

- 🇪🇨 **Guayaquil**
- 🇪🇨 **Manta**
- 🇪🇨 **Quito**
- 🇪🇨 **Cuenca**

## ✨ Características

- 🌡️ Consulta de temperatura.
- 💨 Información sobre velocidad del viento.
- 🏙️ Selección entre diferentes ciudades del Ecuador.
- 📊 Visualización de información meteorológica.

## 🏙️ Ciudades disponibles

| Ciudad | Región |
|---|---|
| Guayaquil | Costa |
| Manta | Costa |
| Quito | Sierra |
| Cuenca | Sierra |

## 🛠️ Tecnologías utilizadas

- **Ionic**
- **React**

## 🌐 Fuente de datos

Los datos meteorológicos son obtenidos mediante la **Open-Meteo API**, que proporciona información meteorológica para las diferentes ubicaciones seleccionadas.


## 🎯 Objetivo del proyecto

El objetivo de esta aplicación es desarrollar una herramienta móvil sencilla que permita consultar información meteorológica de diferentes ciudades del Ecuador, aplicando conocimientos de desarrollo con React y consumo de APIs.

## 👨‍💻 Proyecto

**Aplicación Meteorológica de Ecuador**

Desarrollada como proyecto académico/práctico de desarrollo de aplicaciones móviles.
